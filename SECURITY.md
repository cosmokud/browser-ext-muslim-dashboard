# Security Policy

## Supported Versions

Security fixes are currently prioritized for the latest minor release line.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1.0 | No        |

## Reporting a Vulnerability

Please report vulnerabilities privately.

Preferred channel:

- GitHub Security Advisories (private):
  https://github.com/cosmokud/browser-ext-muslim-dashboard/security/advisories/new

If private advisories are unavailable in your environment, open an issue and
request private contact without disclosing exploit details:

- https://github.com/cosmokud/browser-ext-muslim-dashboard/issues/new

## What to Include in a Report

- A clear description of the vulnerability
- Impact and affected components
- Reproduction steps or proof of concept
- Browser and extension version details
- Any suggested remediation

## Disclosure Process

- We will acknowledge receipt as soon as possible.
- We will validate and triage the report.
- We will work on a fix and coordinate release timing.
- We will credit reporters who want attribution, after the fix is published.

## Scope

This policy applies to the code and assets in this repository and official
release artifacts generated from it.
